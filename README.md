# chat-socket 💬

A real-time WebSocket chat application built with **Node.js**, **Socket.io**, and a modern **Glassmorphic UI**.

## ✨ Features

- **Real-Time Messaging**: Powered by Socket.IO for low latency.
- **Modern Glassmorphic UI**: Ambient glowing gradients, frosted glass panels, and crisp typography.
- **Interactive Join Modal**: Custom nickname input with live dynamic avatar color generator.
- **Audio Notifications**: Notification chime on incoming messages (`tin.mp3`) with mute/unmute toggle.
- **Quick Reaction Bar**: Send instant emoji reactions (`👋`, `🔥`, `👍`, `❤️`, `🚀`, `😂`).
- **Emoji Picker**: Built-in popover picker with 16 quick emojis.
- **Status Indicators**: Live WebSocket connection badge (Connected / Offline).
- **Responsive Design**: Optimized for desktops, tablets, and mobile devices.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/shreyasmogaveera/chat-socket.git
cd chat-socket
```

### 2. Install & Start Node Server
```bash
cd "Node Server"
npm install
node index.js
```
The server will run on port `8000`.

### 3. Open Frontend
Open `index.html` in your browser (or use Live Server).

## 🛠️ Tech Stack
- **Frontend**: HTML5, Vanilla CSS3 (Glassmorphism & Flexbox), Vanilla JavaScript (ES6+)
- **Backend**: Node.js, Socket.io
